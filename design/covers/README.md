# Fontes das capas dos projectos

As capas `assets/images/projects/cisd-cover.webp` e `kwatisa-cover.webp` são
ilustrações originais desenhadas em HTML/CSS (sem textos, logótipos ou dados
inventados) e exportadas a 1600×900 (16:9).

Para as regenerar depois de editar `cisd.html` ou `kwatisa.html`:

1. Abra o ficheiro no Chrome com a janela a 1600×900 (DevTools → modo dispositivo → 1600×900).
2. DevTools → `Ctrl+Shift+P` → "Capture screenshot".
3. Converta o PNG para WebP (ex.: https://squoosh.app, qualidade ~85) e substitua o ficheiro em `assets/images/projects/`.
